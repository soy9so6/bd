# Отчёт по практическому заданию
## Использование нереляционных баз данных на практике

### Цель работы
Изучить применение нереляционных баз данных на практике и реализовать программный проект, в котором NoSQL-хранилища взаимодействуют с основным приложением.

### Описание проекта
Разработан REST API-сервис для управления задачами на Python с использованием FastAPI. В проекте используются три системы хранения данных: PostgreSQL, MongoDB и Redis.

PostgreSQL является основной реляционной базой данных. В ней хранится информация о задачах: идентификатор, название, описание, статус и дата создания.

MongoDB применяется для хранения журнала аудита. Каждое действие пользователя формирует отдельный документ с названием события, идентификатором задачи, дополнительными данными и временем выполнения. Документная модель удобна тем, что разные события могут содержать разные наборы дополнительных полей.

Redis используется как кэш. При первом запросе задачи приложение получает данные из PostgreSQL и сохраняет их в Redis на 60 секунд. При повторном запросе данные возвращаются из Redis. При обновлении или удалении задачи соответствующий ключ кэша инвалидируется.

### Реализованные операции
- создание, получение, изменение и удаление задач в PostgreSQL;
- запись событий `task_created`, `task_updated`, `task_deleted` в MongoDB;
- чтение журнала событий из MongoDB;
- кэширование результатов чтения в Redis;
- установка времени жизни кэша (TTL) в 60 секунд;
- удаление устаревшего кэша при изменении данных;
- получение общей статистики по трём хранилищам.

### Результаты
В результате создано приложение, демонстрирующее взаимодействие с нереляционными базами данных двух типов: документоориентированной MongoDB и хранилищем ключ-значение Redis. На примере проекта показано, что NoSQL-технологии могут дополнять реляционную базу данных: MongoDB подходит для гибкого журнала событий, а Redis — для ускорения часто выполняемых операций чтения.

### Вывод
Цель работы достигнута. Реализован и подготовлен к запуску мини-проект, в котором нереляционные базы данных используются для конкретных практических задач. Их применение позволило разделить основное хранение структурированных данных, хранение событий и кэширование.
